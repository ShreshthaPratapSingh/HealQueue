# HealQueue

HealQueue is a real-time doctor appointment and queue management system designed to reduce waiting time, improve clinic efficiency, and provide transparency to patients.

---

## Overview

HealQueue bridges the gap between digital booking and real-world clinic operations by introducing a **live queue tracking system** combined with **clinic-side control**.

Instead of blindly waiting, patients can see their exact position in the queue, while clinics can manage patient flow in real time.

---

## Problem Statement

Current appointment systems:
- Do not reflect real-time doctor availability  
- Cause long and unpredictable waiting times  
- Lack coordination between app and clinic  
- Fail to handle walk-in patients effectively  

---

## Solution

HealQueue provides:
- Real-time queue visibility  
- Accurate wait-time estimation  
- Clinic-side queue management  
- Hybrid system (walk-in + online patients)  

---

## Key Features (Demo Scope)

### Real-Time Queue Tracking
- View "Now Serving" patient  
- See your queue position  
- Live updates as queue progresses  

---

### Clinic Integration (Receptionist Dashboard)
- Manage full queue  
- Move to next patient  
- Maintain real-world sync  

---

### Walk-in + Online Hybrid Model
- Patients can join queue remotely  
- Receptionist can add walk-ins  
- Unified queue system  

---

## User Roles

### Patient
- View doctors  
- Join queue  
- Track live status  

### Receptionist
- Manage queue  
- Add walk-in patients  
- Control patient flow

## Demo Flow

1. User logs in (Patient or Receptionist)  
2. Patient joins queue  
3. Queue number is assigned  
4. Receptionist manages queue  
5. Real-time updates reflect on patient screen  
6. Walk-in patients can be added
